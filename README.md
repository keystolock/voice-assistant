# Voice Assistant (Python)

A simple Python voice assistant with speech recognition, text-to-speech, and music playback.

## Features
- Speech recognition (convert voice to text)
- Text-to-speech responses
- Music playback from a custom library
- Capable of launching .exe files in system
- Real time weather and news
- Search query on web

## Setup

1. Clone the repository:
   
   git clone https://github.com/username/voice-assistant.git

2. Make virtual Env and activate it:
   
3. python -m venv venv <br>
   source venv/Scripts/activate (for linux/mac/gitbash)

4. Install dependencies:<br>
5. pip install -r requirement.txt

6. Create .env folder with your API Keys:
   
    News_API_Key = {Your api keys}<br>
    Weather_API_key = {Your api keys}


# Usage
Run the progam using : python assistance.py <br>
Say "google" to activate for tasks <br>
Say "exit/stop" to terminate the program
